# Maltego Installation Guide

## What is Maltego?

Maltego is an OSINT tool used to investigate and visualize relationships between publicly available digital information.

## Download

Official website:

https://www.maltego.com/

## Installation Steps

1. Visit the official Maltego website.
2. Navigate to the Products or Downloads section.
3. Select the available Maltego Graph desktop edition.
4. Download the installer for your operating system.
5. Run the installer.
6. Launch Maltego.
7. Create or sign in to your account as required.
8. Open a new graph to begin.

## Verification

Confirm that Maltego launches and allows you to create a new graph.
